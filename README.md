# TASK 5: Host a Static Website with GitHub Pages

## 1. Title Page
- **Task Name:** Host a Static Website with GitHub Pages
- **Intern:** Lavraj Pardhi
- **Program:** DevOps Internship

## 2. Task Objective
Deploy a simple HTML website using GitHub Pages to learn and understand how to host static content for free on the cloud.

## 3. Tools Used
- **GitHub:** Version control and source code repository hosting.
- **GitHub Pages:** Built-in hosting service to deploy static websites directly from a GitHub repository.
- **VS Code:** Local code editor for writing HTML and CSS.

## 4. Project Overview
This project demonstrates the process of building a basic static webpage using HTML and CSS, pushing the code to a public GitHub repository, and enabling GitHub Pages to make the website publicly accessible live on the internet.

## 5. GitHub Repository Setup
- Created a new public GitHub repository named `static-website` to store the project code and assets.
- Initialized a local workspace in VS Code and linked it to the remote GitHub repository using Git commands (`git init`, `git remote add origin`).

## 6. Project Structure
The repository contains the following files:
- `index.html`: The core HTML file containing the content of the webpage.
- `style.css`: The stylesheet used to style and format the webpage layout.
- `README.md`: Documentation explaining the objective, steps, and process of the task.

## 7. HTML Implementation (`index.html`)
Created a clean HTML structure with a main container, header text, and a descriptive paragraph indicating the successful hosting of the static website on GitHub Pages.

## 8. CSS Customization (`style.css`)
Added styling rules to customize the page appearance:
- Set a clean font family and background color.
- Centered the content layout with padding and box-shadow effects for visual appeal.

## 9. Version Control & Git Workflow
Pushed the project files to the GitHub repository using standard Git commands:
- `git add .` to stage files.
- `git commit` to save the snapshot with a descriptive commit message.
- `git push -u origin main` to upload the code to the main branch.

## 10. GitHub Pages Configuration
- Navigated to the repository **Settings** on GitHub.
- Selected the **Pages** tab under the code and automation section.
- Configured the deployment source to deploy from the `main` branch and `/ (root)` folder, then saved the settings.

## 11. Live Deployment Result
- After a short build time, GitHub Pages generated a live public URL for the website.
- Accessing the provided URL successfully loaded the hosted static website.

## 12. Complete Deployment Flow
Local VS Code Directory 
↓
Create index.html & style.css
↓
Git Init & Commit Changes
↓
Push Code to GitHub Main Branch
↓
Open Repository Settings → Pages
↓
Enable GitHub Pages (Main Branch / Root)
↓
Website Live Successfully
